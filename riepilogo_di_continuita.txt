--------------------------------------------------------------------------------
2. BUS LWS v1.1 — PROTOCOLLO
--------------------------------------------------------------------------------

Frame:
  [SENDER][SEQ][CMD][LEN][PAYLOAD...][CRC8][&][!]

  - SENDER   : 1 byte, ID del nodo mittente
  - SEQ      : 1 byte, sequence number (0..255)
  - CMD      : 1 byte, codice comando
  - LEN      : 1 byte, lunghezza payload (0..255)
  - PAYLOAD  : LEN byte
  - CRC8     : CRC-8/ATM (poly 0x07, init 0x00) su SENDER..PAYLOAD
  - '&' '!'  : terminatori fissi

Vincolo: '&' (0x26) e '!' (0x21) non devono comparire nel payload.

Baud rate:
  - UART hardware: 1 Mbps
  - SerialPIO: 115200
  - MIDI hardware: 31250


--------------------------------------------------------------------------------
3. CMD CODES (serial_protocol.h condiviso)
--------------------------------------------------------------------------------

CMD base:
  CMD_PING          'p'   [target]
  CMD_PONG          'P'   (vuoto)
  CMD_PARAM         'S'   [target][key][value]
  CMD_PARAM_REL     'R'   [target][key][value] + ACK
  CMD_PARAM_ACK     'A'   [acked_seq][acked_cmd]
  CMD_ERROR         'E'   [target][msg...]
  CMD_TIMELINE      'B'   [cur_ms i32][tot_ms i32]
  CMD_MIDI_CC       'c'   [cc][value]
  CMD_MIDI_NOTE     'n'   [onoff][pitch][vel]
  CMD_MIDI_BEND     'b'   [bend i32]
  CMD_DRUM_PATTERN  'W'   [ptn_num][name...]

CMD estesi SynthA (con voice/target):
  CMD_PARAM_VOCE    'V'   [target][voice][key][value]
  CMD_PARAM_I32     'I'   [target][key][i32_le]
  CMD_PARAM_I32_V   'J'   [target][voice][key][i32_le]
  CMD_MIDI_NOTE_V   'N'   [target][voice][onoff][pitch][vel]
  CMD_MIDI_BEND_V   'M'   [target][voice][bend i32_le]
  CMD_MIDI_CC_V     'K'   [target][voice][cc][value]

CMD preset transfer:
  CMD_PRESET_BEGIN       'b'  [target][voice][id][len_lo][len_hi]
  CMD_PRESET_CHUNK       'h'  [target][voice][off_lo][off_hi][data...]
  CMD_PRESET_END         'e'  [target][voice][crc8]
  CMD_PRESET_ACK         'a'  [target][voice][status]
  CMD_PRESET_READ        'r'  [target][voice][id]
  CMD_PRESET_DUMP_BEGIN  'K'  [voice][len_lo][len_hi]      <-- COLLISIONE
  CMD_PRESET_DUMP_CHUNK  'L'  [voice][off_lo][off_hi][data]
  CMD_PRESET_DUMP_END    'O'  [voice][crc8]

  ATTENZIONE: 'K' e' usato sia da CMD_MIDI_CC_V che da CMD_PRESET_DUMP_BEGIN.
  Da rinominare uno dei due (es. CMD_PRESET_DUMP_BEGIN = 'Q').

Status ACK preset:
  0 = OK
  1 = CRC_FAIL
  2 = LEN_FAIL
  3 = VER_FAIL
  4 = BUSY

5. LUD-WS-ROUTER (Pico 2) — v0.0.5 — COMPLETO
--------------------------------------------------------------------------------

File: Lud-WS-Router.ino

UART mapping:
  Serial1 (UART0)   GP0/GP1   @ 1 Mbps    -> Teensy
  Serial2 (UART1)   GP4/GP5   @ 1 Mbps    -> Display
  SerialSynthA      GP2/GP3   @ 115200    -> SynthA catena
  SerialSynthB      GP8/GP9   @ 115200    -> SynthB legacy

Funzionalita':
  - Bridge Display <-> Nodi (forward per target)
  - MIDI hardware -> CMD_MIDI_*_V verso SynthA + telemetria al Display

  - Discovery (PING/PONG)
  - Heartbeat 1 Hz verso Display

Funzioni principali:
  - isLwsNode(id)             : true per T, a, b, c
  - portForNode(id)           : ritorna Stream* per target
  - targetForVoice(voice)     : 0->a, 1/2->b, 3/4->c
  - forwardPingToNode(target) : PING LWS o legacy
  - forwardParamToNode(f)     : forward CMD_PARAM, CMD_PARAM_VOCE, ecc.
  - forwardMidiVToSynthA(f)   : forward CMD_MIDI_*_V
  - pollNodePorts()           : bridge nodi LWS -> Display
  - handleNodePong()          : legacy PONG -> LWS

7. LUD-WS-SYNTHA (RP2040) — rev 9 — COMPLETO
--------------------------------------------------------------------------------

Tre chip da UN SOLO sketch, differenza solo per #define MCU_ID:

  MCU_ID 'a'  ->  NUM_VOCI=1, VOCE_BASE=0  (Master, 1 voce + bridge)
  MCU_ID 'b'  ->  NUM_VOCI=2, VOCE_BASE=1  (V_A, 2 voci + relay)
  MCU_ID 'c'  ->  NUM_VOCI=2, VOCE_BASE=3  (V_B, 2 voci, no relay)

File:
  Lud-WS-SynthA_M.ino       bootstrap, setup, loop, definizione variabili
  synthConfig.h             config chip + chiavi K_*
  synthState.h              extern variabili globali
  synthEngine.h             IRQ PWM, ADSR, note stack, wavetable, glide
  synthControl.h            LFO mod/pitch per-voce, arp, gater
  synthLws.h                callback, bridge, Poly broadcast, preset
  synthPreset.h             utility preset (buffer + parser K-V)

                            bendMaxUpArr[5], bendMaxDownArr[5]
  serial_protocol.h         condiviso
  comunicazioni_mcu.h       condiviso

Modello voci:
  - Ogni voce e' un synth MONOFONICO
  - Ogni voce ha 2 SUB_VOCI (oscillatori):
      sub_voce 0: nota base
      sub_voce 1: nota base + interval (semitoni, -24..+24)
      sub_voce 1 ha il suo waveform + subLevel
  - ADSR per-voce (A D S R, 0..255)
  - Note stack (priorita' alle note premute, NoteOff torna alla precedente)
  - Glide/slide per-voce (0..1s)
  - FM operator parameters condivisi (fmSetSin[8][3], fmSetDiv[8][3])

Modi:
  Poly (K_SYNTH_MODE=0):
    Tutte le voci eseguono lo stesso preset.
    Il Master 'a' broadcasta automaticamente i comandi della voce 0
    verso le voci 1,2 (a 'b') e 3,4 (a 'c').
  MultiMono (K_SYNTH_MODE=1):
    Ogni voce indipendente. Il Display indirizza esplicitamente
    ogni voce con il byte voice nel payload.

Porte:
  'a': LWS_PORT_UP = SerialPIO(2,3) @ 115200 (verso Router)
       LWS_PORT_DOWN = Serial1 (UART0) @ 1 Mbps (verso 'b')
  'b': LWS_PORT_UP = Serial1 @ 1 Mbps
       LWS_PORT_DOWN = Serial2 (UART1) @ 1 Mbps (verso 'c')
  'c': LWS_PORT_UP = Serial1 @ 1 Mbps
       HAS_DOWNSTREAM = 0

Bridge:
  Master 'a': frame con target != 'a' -> forward su DOWN
              frame da DOWN -> forward su UP (verso Router)
  Slave 'b':  identico
  Slave 'c':  solo UP (no DOWN)

Poly broadcast (solo 'a'):
  Se synthMode == Poly e arriva CMD_MIDI_*_V o CMD_PARAM_*_V con voice 0,
  replica il frame per voci 1,2,3,4 e li invia su DOWN.

Chiavi LWS per voce (uint8, CMD_PARAM_VOCE):
  m   mode (0=WF, 1=FM, 2=AM)

  k   tracking (keytracking)
  d   detune (0..100)

  3   vcf multi (0..12)

  u   bend max up (0..4)
  n   bend max down (0..4)
  B   send bend (0/1)

  y   lfo mod sync (0/1)
  D   dsp slot (0..15)
  r   arp on (0/1)
  R   arp mode (0/1/2)
  A   arp multi (0..4)
  T   arp octaves (0..2)
  g   gater on (0/1)
  G   gater num (0..7)
  H   gate multi (0..4)
  L   gate lung (0..99)
  O   conta offset (0..255)
  C   midi channel (1..16)
  Z   nota split (0..108)
  X   midi mode (0..3)
  e   sub1 level (0..20)
  9   voice vol (0..20)
  5   ADSR attack (0..255)
  6   ADSR decay (0..255)
  7   ADSR sustain (0..255)
  8   ADSR release (0..255)

Chiavi LWS per voce (int32, CMD_PARAM_I32_V):
  i   mod in B (0..1023)
  I   mod level (0..1023)
  f   lfo rate (350..80000 us, inverso)
  j   pitch level (0..550)
  J   pitch rate (350..80000 us)
  x   FM sin 0 (float*100)

  q   FM div 0 (1..600)
  Q   FM div 1

  h   sub1 interval (-24..+24)

Chiavi globali chip (CMD_PARAM_I32):

Chiavi sistema (CMD_PARAM, solo Master):

  P   preset select (0..29)
  Q   preset save (0..29)
  U   voice mute (0/1)

10. SISTEMA PRESET (fase A — completa lato codice)
--------------------------------------------------------------------------------

Struttura file su SD:
  /preset/
    synthA/
      preset_00.bin .. preset_29.bin     (30 file)
      nomi_presetA.txt                    (30 righe)
    synthB/
      preset_00.bin .. preset_29.bin
      nomi_presetB.txt

Uso:
  Poly:       loadPresetSynthA_Poly(presetId)
              -> carica lo stesso blob sulle 5 voci
  MultiMono:  loadPresetSynthA_MultiMono(map[5])
              -> map[i] = preset per voce i
  SynthB:     loadPresetSynthB(presetId)

  Save A:     savePresetA(voice, presetId)   (serializza cacheA[voice])
  Save B:     savePresetB(presetId)

Flusso load:
  Display legge .bin da SD
    -> popola cache
    -> invia blob con CMD_PRESET_BEGIN/CHUNK/END
    -> attende CMD_PRESET_ACK

Flusso save:
  Display serializza cacheA/B in K-V
    -> scrive file .bin su SD

16. FILE PYTHON GENERATOR PRESET

Script che serializza K-V + CRC per generare i file .bin.

  import struct
  def crc8(data):
      crc = 0
      for b in data:
          crc ^= b
          for _ in range(8):
              crc = ((crc << 1) ^ 0x07) & 0xFF if (crc & 0x80) else (crc << 1) & 0xFF
      return crc

  def entry(key, val, fmt):
      v = struct.pack('<' + fmt, val)
      return bytes([ord(key), len(v)]) + v

  def build_preset(params):
      buf = bytes([0x01])
      for k, v, f in params:
          buf += entry(k, v, f)
      buf += bytes([0xFF])
      buf += bytes([crc8(buf)])
      return buf

  Salva in /preset/synthA/preset_NN.bin o synthB.

  nomi_presetA.txt -> 30 righe di testo (una per preset)
  nomi_presetB.txt -> idem
